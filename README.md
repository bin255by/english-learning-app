# 轻轻学英语 · English Learning App for Chinese Middle-Aged Beginners

> 面向英语初学者的**纯前端、移动端优先**英语学习网站：**所有英文都能点击朗读**（像 Google 翻译那样，中文不朗读），内置词根词缀、场景对话、主题单词、常用网站与全站模糊搜索，支持「添加到主屏幕」当 App 用、断网也能学。

技术栈：原生 HTML + CSS + JavaScript（ES6 模块），无后端、无构建步骤；第三方库仅 Swiper 11 与 Fuse.js 7（走 CDN，缺库时自动降级）。

---

## 1. 本地启动

```bash
# 方式 A：Python（任选其一，需 Python 3）
cd english-learning-app
python -m http.server 8080

# 方式 B：Node
npx serve .
```

浏览器打开：

- <http://127.0.0.1:8080/index.html>

> ### ⚠️ 不要双击 `index.html` 打开
> 用 `file://` 协议直接打开文件时，浏览器会以跨源（CORS）为由**同时拒绝 ES 模块和 JSON 抓取**：
> `js/app.js` 无法加载、`data/*.json` 的 `fetch` 全部失败，页面表现为白屏 + 控制台一堆红色跨域错误。
> **必须通过 `http://` 访问**（上面的两种方式任选其一）。

> 部署到正式服务器时同理：需要 `https://`（或 `http://`）才能注册 Service Worker、启用离线与「添加到主屏幕」。

## 3. 浏览器要求

| 浏览器 | 硬性下限（功能可用） | 推荐版本（体验最佳） | 说明 |
|---|---|---|---|
| iOS Safari | iOS 14.5 | **iOS 15+** | 朗读首声、Service Worker、flex `gap` 都从这个版本开始稳定 |
| macOS Safari | Safari 14.1 | **Safari 15+** | 同上 |
| Chrome（桌面 / Android） | Chrome 84 | **Chrome 90+** | 84 是 flex `gap` 的下限；Android 需 90+ 才有完整的语音合成体验 |
| Edge | Edge 84 | **Edge 90+** | 与 Chromium 同源 |
| Firefox | Firefox 63 | Firefox 90+ | 可用，但**英语语音包**质量不如 Chrome / Safari |

关键依赖（决定版本下限）：

- **ES Modules**（`js/*.js`）：Chrome 61+ / Safari 10.1+ / Edge 79+
- **CSS flex `gap`**：Chrome 84+ / Safari 14.1+ / Edge 84+ / Firefox 63+
- **Web Speech API（朗读核心）**：Chrome 33+ / Safari 7+；iOS 上建议 14.5 以上，否则可能无声或声音异常
- **Service Worker / PWA**：Chrome 40+ / Safari 11.1+（且必须 `https://` 或 `http://127.0.0.1`）
- **CDN 库**（Swiper 11 / Fuse.js 7）：需要联网；被拦截或离线时页面**自动降级**（轮播变横向滚动、搜索变子串匹配），不会白屏

## 5. 真机验收清单

> **可打印的完整验收表格见 [`docs/真机验收.md`](./docs/真机验收.md)** —— 里面每项都有「步骤 / 预期 / 实际 / 通过·失败 / 截图位置」栏位，直接在那份文件上填写并归档。

> 桌面浏览器通过 ≠ 手机能用。朗读是本项目的核心卖点，**必须真机验证**。每台设备都建议：先开飞行模式关掉 Wi-Fi 之外的干扰，用**真机浏览器**（不要用微信内置浏览器 / 无痕模式）走一遍。

### 5.1 iOS Safari（iPhone，iOS 15+）

- [ ] 用 **Safari** 打开局域网地址：`http://<电脑IP>:8080/index.html`（注意：手机与电脑要在同一个 Wi-Fi；`127.0.0.1` 在手机上指的是手机自己，会打不开）
- [ ] 页面顶部**先点一下**屏幕任意处解锁音频，然后点任意英文单词 → **应立即发声**（iOS 首次必须由用户手势触发）
- [ ] 连续快速点读 3 个不同单词 → 每次都应朗读新内容、不重叠、不卡死
- [ ] 切到 💬 场景对话 →「整段播放」应连续朗读并显示 `朗读中 2/4` 进度徽标；「停止朗读」能立刻闭嘴
- [ ] 顶部语速切到 0.7 / 0.85 / 1.0 → 每次应试听一句，语速差别明显
- [ ] 中文（例句下方的灰色中文）**点一下不应发声**
- [ ] 搜索框输入 `vitamin`（故意拼错）→ 应能搜到 `vegetarian` 一类的容错结果；点结果能跳转并高亮
- [ ] 点卡片右上角 ☆ → 变 ★ 且 toast 提示；回到首页「我的收藏」能看到该条目，**刷新后仍在**
- [ ] 点「打开网站 →」→ 应在**新标签页**打开，本页面不被替换
- [ ] 点底部「分享」→「添加到主屏幕」→ 桌面出现「轻轻学英语」图标；从主屏启动应**全屏无地址栏**
- [ ] 打开飞行模式后从主屏图标启动 → 5 个 Tab、搜索、收藏、朗读都应仍可用（维基摘要会取不到，属预期）
- [ ] 刘海屏机型检查：底部 Tab 栏不被 Home 指示条遮住，顶部不被状态栏遮住

### 5.2 Android Chrome（Android 10+，Chrome 90+）

- [ ] Chrome 打开同一局域网地址，DevTools 无红色报错
- [ ] 点任意英文 → 立即发声；快速连点、反复点不出现叠音
- [ ] 出现「添加到主屏幕」提示条 → 点「添加到主屏幕」→ 桌面生成图标；提示条应消失
- [ ] 从桌面图标启动 → 独立窗口（无地址栏），底部 Tab 栏被手势条适配
- [ ] 对话「整段播放」进度徽标与「停止朗读」均正常
- [ ] 切后台再切回 → 朗读应已停止，不出现「一直读」的情况
- [ ] 语速三档 + 收藏 + 搜索跳转高亮 + 网站新窗口打开，逐项与 iOS 结果一致
- [ ] 开飞行模式重开 App → 离线可用（同上）

### 5.3 交付前最小回归（桌面 Chrome 即可）

- [ ] 5 个 Tab 逐个点开，控制台 **0 error**
- [ ] 顶部搜索输入 `spec`、`一月`、`wikipedia` 三种词，都能出结果并正确跳转
- [ ] 全程只点英文，中文不朗读

## 7. 日常维护

- **加单词**：编辑 `data/vocabulary.json`，在某分类的 `items` 里追加一条 `{ "en", "zh", "exampleEn", "exampleZh" }`（有简写的再加 `"abbr"`，如 `"1st"`），刷新页面即可，无需改代码。
- **加网站**：编辑 `data/websites.json`，字段为 `nameEn` / `nameZh` / `url` / `descEn` / `descZh`；`url` 一律用 `https://` 开头，卡片会自动以新窗口打开。
- **离线缺资源**：`sw.js` 的 `SHELL_ASSETS` 是手写清单，**新增文件必须同步补进去**，并把 `CACHE_VERSION` 往上加一位，否则老用户会继续用旧缓存。
- **数据 JSON 出错**：页面会显示「数据加载失败」并把报错打在控制台；JSON 不允许尾逗号、注释。
- **改完记得跑一遍第 5.3 节的最小回归。**
