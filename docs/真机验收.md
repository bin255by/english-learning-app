# 真机验收清单（iPhone Safari / Android Chrome）

> 本清单用于**交付前真机走查**。项目的核心卖点是「点英文就能朗读」，桌面浏览器通过 ≠ 手机能用。
> 每一项都要**在真机上实际操作**、**如实填「实际」**、**给出「通过/失败」**、**附截图或录屏文件名**。
> 本文件是待填写的表格，不是已完成的报告。

---

## 0. 测试准备

### 0.1 必做前提

1. 电脑与手机连**同一个 Wi-Fi**（手机端不要用 `127.0.0.1`，那指的是手机自己）。
2. 电脑在项目根目录起服务：`python -m http.server 8080`。
3. 查电脑局域网 IP：Windows 执行 `ipconfig`，看「IPv4 地址」，例如 `192.168.1.23`。
4. 手机浏览器打开：**`http://<电脑IP>:8080/index.html`**（例如 `http://192.168.1.23:8080/index.html`）。
5. **音量调到 50% 以上；iPhone 侧边静音拨片拨到「响铃」位置**（A 项要专门测静音拨片的影响）。
6. 手机系统里关掉「低电量模式」和可能拦截通知/后台的省电策略（Android 厂商 ROM 影响很大）。
7. 截图请用**系统截图**，不要用长截图（长截图会截掉状态栏，看不到安全区判断）。
8. PWA 项（F/G）必须**先联网完整打开一次**再断网，否则 Service Worker 还没预缓存，属于无效测试。

### 0.2 打开「真机自测」面板（截图辅助，临时功能）

- 进入 **首页**，滑到最底部有一行灰色小字 **「版本 v0.9.x」**。
- **连点这行版本号 5 次**（5 次之间不要间隔超过 2.5 秒），下方会展开「真机自测」面板。
- 面板显示：**浏览器 UA、页面版本、当前缓存版本（caches 实际名）、Service Worker 注册状态、speechSynthesis 语音列表**。
- 用途：出现「不发声」等怪问题时，**先截这张图**，能立刻看出是没装英文语音包、还是 SW 没注册、还是版本不匹配。
- 该入口为临时调试功能，第 3 轮会删除或改为正式 debug 模式。

### 0.3 截图命名规范

```
<项号>-<平台>-<序号>-<一句话>.png      例：A-ios-1-首次点击发声.png
<项号>-<平台>-<序号>.mp4              连续播放类项目建议录屏
```

平台用 `ios` / `and`。截图统一放在 `docs/shots/` 下（本轮未创建该目录，首次截图时自建）。

### 0.4 结果填写规则

- **通过**：实际表现与「预期」一致，或差异在可接受范围内（差异要在备注写清）。
- **失败**：与预期不符 → 必须同时在第 4 节「问题记录表」登记一行（含机型、系统版本、复现步骤、截图）。
- **不适用**：该机型/系统确实不涉及（例如非刘海屏 iPhone 填 H 项）→ 填「不适用」并说明原因。
- 拿不准的一律记为**失败**并写进问题表，不要默认通过。

## 附录 A · 「真机自测」面板字段说明（第 2 轮加的临时入口，第 3 轮会删或转 debug 模式）

进入方式：**首页 → 滑到底 → 连点灰色版本号 5 次**（5 次之间间隔不要超过 2.5 秒）。

| 面板字段 | 怎么读 | 异常时说明什么 |
|---|---|---|
| 浏览器 UA | 手机型号 / 系统 / 浏览器版本 | UA 里没有 `Safari` 或 `Chrome` → 可能用了微信内置浏览器，需换系统浏览器 |
| 页面版本 | 本次构建的版本常量 | 与 sw.js 的 `CACHE_VERSION` 不一致 → 缓存可能是旧的，需要在 SW 里升版本 |
| 当前缓存版本 | `caches.keys()` 的真实缓存名 | 为空 → SW 没装上，F/G 项必然失败；出现多个 `shell-vX` → 旧缓存没清干净 |
| SW 注册状态 | installing / waiting / active + scope + 是否有 controller | 「无 controller」→ 当前页面不受 SW 接管（首次访问属正常，刷新一次再看） |
| 语音列表 | `speechSynthesis.getVoices()` 全部条目 | **列表为空或没有 `en-US` → 这台设备没装英语语音包，A–E 项必然失败**，需在系统设置里下载英语朗读语音 |
| 协议 / 安全上下文 | `http(s)://…` 与 `isSecureContext` | `file://` → ES 模块与数据都加载不了；非安全上下文 → SW 与通知不可用 |

> 面板会把语音列表原样列出来（可能十几条），**截图请连同版本号一起截全**，便于比对两台设备的语音包差异。
